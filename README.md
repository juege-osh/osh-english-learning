# 英语远征

[english.osh.lol](https://english.osh.lol/) 的完整源代码。普通用户先看 [使用说明.md](使用说明.md)；准备验收时看 [验收手册.md](验收手册.md)；功能及未完成项见 [交付状态.md](交付状态.md)。

当前预览版为 v1.29.6。网站提供 5,000 / 10,000 / 20,000 词通用主线、逐级题型、例句朗读、错词补练和间隔复习。10 条行业和 7 条考试路线可自由选练，另有音标与语法速通；单排、双排、好友和聊天使用服务端持久状态。学习进度先保存在浏览器，登录后同步到账号，也可手动导出导入。本批按觉哥授权完成测试、仓库核验后发布；正式站实际版本见 /api/health，真实支付宝仍未试付。

## 本地运行

需要 Go 1.26 和 Node.js（用于前端语法检查）。

```bash
go run . --port 18999 --state-dir /tmp/english-quest-state
```

打开 `http://127.0.0.1:18999/`。服务仅监听本机地址；生产环境由 HTTPS 反向代理转发。

`build_vocab.py` 与 `build_scenarios.py` 是原始数据构建脚本；`build_tracks.py` 从 ECDICT 标签生成考试参考池。`build_industries.py` 读取每行业前 100 词的起步编辑层，再按 `qa/<行业ID>_reviewed.tsv` 替换扩展池、按 `qa/<行业ID>_examples.tsv` 加入行业例句。`qa/industry_display.json` 保存行业缩写的标准展示形式；例如IPO、FOB、DNA，大小写不影响搜索，学习记录仍用原编号。`qa/industry_confusables.json` 记录句子题需要避开的近义词组；相同中文义的词也会排除。有完整编辑表的行业不再用关键词凑数；当前十条行业都有编辑表，不再使用自动试练扩展池；构建器仍保留未编辑路线的标注逻辑。程序员683词、外贸774词、金融846词、AI创作831词、市场营销767词、医疗健康753词、生物科学967词、法律850词、化学与材料932词、旅行709词已整理行业含义。十条行业路线共8112个条目、16224句，每个条目都有两句行业用法。缺少的专业词写入独立的 `data/industry_words.json`，现有1407词；编号只追加，不改变主线20,000词或考试池。运行原始构建需要 ECDICT CSV，已生成数据随仓库提供，正常启动不需要下载。

服务启动时会把嵌入的静态文件读入一次，并预先计算 ETag。2026 年 9 月 30 日在本机用 20 个并发连接下载 40 次大词库文件，旧实现进程内存峰值约 129 MB，新实现约 37 MB；用 50 个连接下载 100 次时约 43 MB。这是本机静态文件测试，不代表正式站多人竞技的容量。

## 音标、语法与手机使用

音标速通采用常见英式44音教学符号。先看口型提示和示例词，再听音选四选一；每个音标的两次听音都答对才通过。44条真实参考音频随程序打包，开放许可、作者、来源及处理说明见 [provenance/phonics-audio.md](provenance/phonics-audio.md)。不同素材的口音、长音时值和辅助元音存在差异，卡片已有说明；尚未经过专业教师逐条听审。

语法速通有36个知识点，分为基础、时态、表达、句型。每点读一条规则和一句双语例句，再做选择题、键盘填空各一次；两类题都答对才通过，错题留到本轮末尾补练。两套课程的通过记录独立保存，登录后可跨设备合并，不增加主线词汇量或段位。

旅行专项有709词，全部配1418句双语沟通用法，覆盖机场、住宿、交通、餐饮与求助。专项答题后的释义和例句默认收起，点「查看释义与例句」展开并逐句播放。手机底部保留4个常用入口，其余9个入口在「更多」里。

v1.26.0已做并发与小屏布局验收；后续内容批次的实际检查见文末，不把旧版测量当作本轮重测。

## 站长操作

持久目录由 `--state-dir` 指定。生产环境为 `/var/lib/english-quest`，应只允许服务账号读取并定期做私密备份。目录包含账号密码哈希和登录会话、云端闯关进度、会员有效期、关注截图、预约联系信息、好友、竞技赛与聊天记录，不要提交到仓库或公开备份。

生产备份定时器每天运行一次，归档放在 `/var/backups/english-quest`，只有 root 能读取。它不会自动删除旧备份；应定期检查容量并制作异地副本。恢复前先停服务，将归档解压到隔离目录核对，再覆盖状态目录并确认属主和权限。备份只是数据副本，不能代替恢复演练。

2026 年 9 月 30 日已用隔离测试数据做过一次恢复演练：备份归档通过校验，解压内容与源目录逐文件一致；从还原目录启动服务后，测试账号可以登录并读到原有学习进度。正式站的数据仍需另行做一次受控恢复演练。

站长先在网站自行注册。随后在服务器上执行：

```bash
/opt/english-quest/english-quest-linux --state-dir /var/lib/english-quest --promote-admin 站长账号名
```

刷新免费申请页即可审核截图。站长账号支持人工通过或拒绝，每次通过增加 30 天交流权益。站长可在同一页的「关注主页与入群设置」填写五个平台主页、联系微信及入群说明。主页对所有人显示；入群信息仅有效会员和站长能读取。实际链接与联系方式待站长填写。

「生成兑换码」支持月卡 30 天、年卡 365 天和永久权益。生成后立即复制保存，页面不会列出旧码。用户登录后在「兑换交流权益」输入，代码只能用一次，权益绑定账号；已有剩余天数会顺延。兑换状态和权益一起保存，服务重启后不能重复使用。

在站长账号的 **免费申请 → 连麦预约管理** 可以直接查看并确认预约。需要离线处理时，查看预约：

```bash
/opt/english-quest/english-quest-linux --state-dir /var/lib/english-quest --list-bookings
```

确认预约：

```bash
/opt/english-quest/english-quest-linux --state-dir /var/lib/english-quest --confirm-booking '预约ID' --confirm-time '2026-10-10 19:00 北京时间'
```

该命令的输出会包含用户联系方式，只能在私密终端查看。
